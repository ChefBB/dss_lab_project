\subsubsection*{Assignment 7 -- Duplicazione dei Dati di Test}
L'Assignment 7 prevedeva la duplicazione delle tabelle del Data Warehouse
definite nell'Assignment 4 e la popolazione delle nuove tabelle con un
sottoinsieme pari al 30\% dei dati.  
Le tabelle duplicate, denominate \texttt{TABLENAME\_SSIS}, sono state
create tramite SQL Server Management Studio (SSMS) utilizzando la query
\texttt{assignment\_7/table\_dup.sql}.\\

La popolazione delle tabelle duplicate è stata realizzata mediante
SQL Server Integration Services (SSIS). Il Data Flow utilizzato è
mostrato in Figura~\ref{fig:sampling}.

\begin{figure}[H]
    \centering
    \includegraphics[width=1\textwidth]{Figures/Screenshot 2025-12-30 at 16.04.31.png}
    \caption{Data Flow SSIS per la popolazione delle tabelle di test}
    \label{fig:sampling}
\end{figure}

Il processo di popolazione si basa su un campionamento casuale del 30\%
delle canzoni, utilizzate come riferimento per selezionare i record
correlati nelle altre tabelle tramite le relazioni definite nello schema
del Data Warehouse. Questa scelta consente di mantenere la coerenza
referenziale tra fact table e dimension tables.

Il campionamento è stato applicato a livello di canzone, poiché
rappresenta l'entità centrale del modello analitico. Le dimensioni
associate possono quindi contenere una percentuale di record superiore
al 30\%, in quanto necessarie a garantire la completezza delle
informazioni per le canzoni selezionate.
